# 德国移民数据智能分析平台用户操作指南 (User Guide)

欢迎使用**德国移民数据智能分析平台 (Germany Migration Intelligence Dashboard)**。本平台专为人口学研究者、政策分析人员、涉外律所及数据分析爱好者打造，提供全交互、高精度、可持续更新的德国官方移民与入籍统计分析能力。

---

## 一、平台快速启动

### 方法 A：一键命令行启动（推荐）
在终端中进入项目主目录并执行启动脚本：
```bash
cd /Users/ashan/.gemini/antigravity/scratch/germany-migration-dashboard
./run.sh
```
或者直接使用 Python 启动本地 Web 服务器：
```bash
python3 server.py
```
启动后，在任意浏览器中打开：
👉 **http://127.0.0.1:8080**

### 方法 B：离线无服务直接打开
本平台具备**100% 离线自包含运行架构**。您无需安装任何第三方 Node 依赖或 Python Web 框架，直接在文件管理器中双击 `index.html` 即可在本地浏览器中完整浏览、交互、查询及筛选全部图表数据！

## 二、核心功能与交互操作说明

### 1. 中英文界面一键切换 (Language Toggle)
* 位于网页**右上角导航栏**：设有 `中文 | English` 切换胶囊按钮；
* **默认语言**：简体中文；
* **切换机制**：点击 `English` 后，页面标题、导航菜单、所有 7 项 KPI、图表标题、坐标轴、筛选器、数据字典说明、智能归因洞察及 BI 检索表将瞬时无缝切换为英文；
* **记忆持久化**：系统基于浏览器 `localStorage` 自动记忆您的语言选择，刷新页面或重新打开系统将保持上次设定。

### 2. 明暗主题切换 (Dark / Light Theme)
* 点击右上角 `☀️ Light` / `🌙 Dark` 按钮，可在研究级深色模式与高采光浅色模式间随心切换。

### 3. 全局多维联动筛选系统 (Global Filters)
在顶部筛选控制台中，您可以按需组合以下条件：
* **时间范围**：支持快速切换“全部年份 (2000-2026)”、“近20年 (2006-2025)”、“近10年”或“近5年”；
* **国籍筛选**：支持快速定位中国（CN）、印度（IN）、越南（VN）、德国（DE）、波兰（PL）、土耳其（TR）等；
* **群体分类**：德国公民、其他欧盟公民、非欧盟第三国公民；
* **迁移方向**：移入 (Zuzüge)、迁出 (Fortzüge)、仅看净移民 (Saldo)；
* **联邦州选择**：筛选 16 个联邦州的细分表现；
* **重置按钮**：点击“重置所有筛选”可一键恢复初始全局全量视图。

### 4. 模块导航与深层分析
* **模块一：移民总览**：支持在图表右上角自由切换“年度视图”与“月度视图 (2020-2026)”。柱状图采用绿色表示净流入，红色表示净流出；
* **模块二：历史趋势**：双折线展示历年移入量与迁出量走势，并标注 2004 欧盟东扩、2015 难民危机、2016 口径调整、2020 疫情与脱欧、2022 乌克兰战事及 2024 新国籍法改革等重大历史里程碑；
* **模块三：国籍对比**：重点展示中国、印度、越南、波兰、乌克兰、叙利亚等在德移民的结构性差异，支持横向对比与排名；
* **模块四：三大互斥群体**：严格划分德国籍、欧盟籍（不含德）及非欧盟籍，并说明英国脱欧在 2020 年前后的分类变动；
* **模块五：德国公民迁出**：分析瑞士、奥地利、美国等德国人主要外迁目的地，并附有关于“高学历流失推论缺乏登记证据”的严谨边界说明；
* **模块六：联邦州分布**：16 州国际净迁徙横向排名柱状图；
* **模块七：入籍专题**：展示 2000—2025 年入籍趋势，严谨辨析“入籍属于法律身份变更，绝非新增物理入境移民”；
* **模块八：完整数据查询与导出**：支持多维模糊检索、全字段升降序点击排序、真分页（15条/页）及一键导出 CSV/JSON；
* **模块九：发现 (Executive Consulting Deck)**：采用麦肯锡/BCG 顶层战略咨询金字塔原理 (Top-Down Storytelling)，专为高管层与决策智库打造的 5 页交互式咨询简报：
  - **Slide 1 宏观范式重塑**：2000-2026 从“传统非移民国认知”向“高度依赖型移民国家”的三阶段历史范式演进；
  - **Slide 2 结构性双向分化**：本国劳动力向高净值腹地外流（年均净流出 ~8-10 万）与非欧盟第三方技术劳力填补缺口；
  - **Slide 3 微观关键国籍图谱**：中国（高位双向流转/学业流动）、印度（IT/高端技术主力）、越南（护理与双元制技工）的三元生态分化；
  - **Slide 4 制度红利与入籍激增**：2024 年德国《国籍法现代化法案》（允许双重国籍）引发的历史性入籍井喷（2025年达 33.3 万人）；
  - **Slide 5 商业与宏观策略启示**：企业用工策略（技术蓝卡与海外直接雇佣）、法务合规风险与国家社会融合治理路线图；
  - **交互支持**：支持键盘左右方向键（`←` / `→`）翻页、上方胶囊标签快速跳转、以及“全景九宫格总览”与“单页专注”视图自由切换。
* **智能归因分析**：提供 2022 峰值至 2025 回落的 97.6% 迁入减少归因恒等式分解与瀑布流测算。

## 三、数据下载与导出

在页面下方的“模块八：完整数据查询”中：
1. **关键词搜索**：在输入框中输入年份（如 `2024`）、状态（如 `final`）或指标，表格将实时过滤；
2. **下载 CSV 表格**：点击“下载 CSV 表格”，系统将生成并自动下载标准 `.csv` 文件，可直接导入 Excel、Stata 或 R 语言进行统计建模；
3. **下载 JSON 原始数据**：点击“下载 JSON 原始数据”，可获取包含全部元数据、各维度子表的结构化 `.json` 全量数据库。

## 四、数据更新与自动刷新机制

### 1. 手动触发即时更新
点击网页右上角的 **“更新官方数据”** 按钮，系统将向本地后台发送请求，自动执行：
`Destatis API 抓取 -> 数据清洗标准化 -> 恒等式数学质量检验 -> 前端数据重载`。

### 2. 自动化计划任务调度 (Weekly Refresh Job)
系统已配置好每周一次的自动化同步任务：
* **调度频率**：每周一上午 08:00
* **执行时区**：`Europe/Berlin`（柏林时间）
* **守护进程启动方式**：
  ```bash
  python3 etl/scheduler.py --daemon
  ```
* **单次测试执行方式**：
  ```bash
  python3 etl/scheduler.py --once
  ```
更新审计日志将保存在 `logs/refresh_scheduler.log` 中。
